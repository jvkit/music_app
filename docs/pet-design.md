# 音河 · 宠物精力板块设计（v2 已评审版）

> v2 变更（按用户拍板）：**精力系统整体作废**；经济改为 **音符（notes）**——任务得音符、音符投喂得经验、
> 升级解锁动作、音符兑换角色（物种，有等级门槛）。经验唯一来源 = 投喂。素材后续提供。

## 1. 核心概念

| 概念 | 说明 |
|------|------|
| 宠物 | **好友对（pair）维度**：A 在聊天页发起"领养邀请"，B 同意即共同解锁一只宠物。一对好友 = 一只宠物，双方共同养成，**任务进度、音符、经验、等级全部共享**。 |
| 音符 | 唯一货币。做每日任务/签到获得；用途：投喂宠物换经验、兑换新角色（物种）。 |
| 经验/等级 | **唯一来源是投喂音符**。前期快、后期约 2 倍坡度。升级解锁新动作（自动进图鉴）。 |
| 角色（物种） | 用音符兑换，每个角色有等级门槛（如 Lv5 解锁兑换资格）。兑换后在已拥有角色间自由切换展示。 |
| 每日任务 | 每天 0 点（服务器时区）统一刷新，随机从任务池抽取。 |
| 续火花（flame） | 当天"签到 + 完成 ≥2 个任务"记活跃日；连续活跃天数越多，任务音符奖励加成越高；断签衰减清零。 |

## 2. 数据模型（服务端）

`config/pets.json`，key = `pair_key = "|".join(sorted([a, b]))`，写入复用 RLock + 临时文件原子写模式。

```jsonc
{
  "a|b": {
    "members": ["a", "b"],
    "species": "default",             // 当前展示角色
    "species_owned": ["default"],     // 已兑换角色
    "level": 1,
    "exp": 0,
    "notes": 0,                       // 共享音符余额
    "actions_unlocked": ["idle"],     // 升级自动解锁
    "flame": { "days": 0, "last_flame_date": "2026-11-01" },
    "signin": { "last_date": null },
    "tasks": {
      "date": "2026-11-01",
      "items": [
        { "id": "t1", "type": "play_songs", "target": 3,
          "progress": 1, "done": false, "claimed": false,
          "notes_reward": 20 }
      ]
    },
    "feed_count": 0,                  // 累计投喂次数（图鉴/成就用）
    "created_at": 1730419200
  }
}
```

### 2.1 任务池（预置，随机刷新）

每天 0 点刷新 **3 个随机任务 + 1 固定签到**。随机槽位：2 简单 + 1 中等，类型不重复。

| type | 描述 | 档位置 | 进度来源 |
|------|------|--------|----------|
| `play_songs` | 听歌 N 首 | 3 / 5 / 8 | 复用 `POST /api/plays`（>80% 记一次） |
| `search_songs` | 搜索 N 次关键词 | 3 / 5 | 客户端搜索行为上报 |
| `like_songs` | 点赞/收藏 N 首 | 2 / 3 | 收藏上报 |
| `listen_together` | 一起听满 N 分钟 | 10 / 20 | 一起听会话累计时长 |
| `chat_msgs` | 与好友互发 N 条消息 | 5 / 10 | WS chat 消息计数 |
| `share_tracks` | 向好友分享/推荐 N 首歌 | 2 / 3 | WS share_track 计数 |
| `signin` | 每日签到（固定槽位） | 1 | 手动点击 |

行为统一由客户端拦截上报 `POST /pet/event`，服务端累加到**该用户参与的所有 pair** 的当日任务
（用户量小不做定向归属）。`listen_together` 由客户端一起听会话累计后上报。

### 2.2 升级曲线与投喂

经验只升不降。**投喂是经验唯一来源**：

| 项目 | 数值 |
|------|------|
| 投喂单价 | 5 音符 / 次 |
| 单次经验 | 10 经验（固定，简单好算） |
| 等级 | 1→5 级：50 / 80 / 120 / 170 / 230；6→10 级：300 / 380 / 470 / 570 / 680；11→30 级：`800 + (L-11)*120`，30 封顶 |

- 1→2 级 = 25 音符 ≈ 1~1.5 天任务量（首日有爽感）；10 级后每级 ≈ 前期 2 倍时长。
- 投喂时宠物播放 `eat` 动作（素材无则播 `happy` 兜底），对方经 WS 实时同步看到。

### 2.3 升级奖励：动作 + 角色商店

- **动作**：每升 1 级自动解锁 1 个新动作（从动作池随机取未解锁的），进图鉴，聊天页点击随机播放池扩大。
  动作池建议：idle（初始）/ jump / spin / dance / sleep / happy / eat / angry / love。
- **角色（物种）商店**：常驻，音符兑换 + 等级门槛：

| 角色 | 价格 | 门槛 |
|------|------|------|
| default（初始赠送） | — | — |
| 角色2 | 200 音符 | Lv3 |
| 角色3 | 500 音符 | Lv8 |
| 角色4 | 1000 音符 | Lv15 |
| 角色5+ | 预留 | 预留 |

### 2.4 奖励数值（音符）

| 行为 | 音符 |
|------|------|
| 签到 | 10 × 火焰加成 |
| 简单任务 | 20 × 火焰加成 |
| 中等任务 | 40 × 火焰加成 |
| 点击互动（戳宠物） | +1 / 次，每天前 10 次有效（纯粘性功能，可砍） |

### 2.5 续火花（flame）

- 当天 **已签到 且 完成任务数 ≥ 2** → 活跃日，`flame.days++`。
- 加成：1-2 天 ×1.0；3-6 天 ×1.2；7-14 天 ×1.5；15-29 天 ×1.8；30+ 天 ×2.0（乘算在任务/签到音符上）。
- 断签：距 `last_flame_date` > 48 小时 → days 清零（给一天缓冲）。
- 聊天页宠物头顶：火焰 + 天数；当天未活跃时火焰变灰预警。

## 3. 接口设计（服务端，前缀 /api）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/pet/pairs` | 我参与的所有宠物（好友名、等级、经验/升级需、音符、火焰、今日任务、签到、已拥有角色） |
| GET | `/pet/pair/{friend}` | 单个详情 |
| POST | `/pet/signin` `{friend}` | 签到（幂等，当天重复签返回已签） |
| POST | `/pet/claim` `{friend, task_id}` | 领取任务奖励（done && !claimed，防重复） |
| POST | `/pet/feed` `{friend, count}` | 投喂：扣音符、+经验、触发升级结算与动作解锁，WS 推 `pet_action: eat` 给对方 |
| POST | `/pet/buy_species` `{friend, species}` | 兑换角色：校验价格+等级门槛+未拥有 |
| POST | `/pet/switch_species` `{friend, species}` | 切换展示角色（限已拥有） |
| POST | `/pet/event` `{type, count}` | 行为埋点，累加当日任务进度 |
| GET | `/pet/shop` | 角色商店列表（价格/门槛/是否已拥有/我的等级是否够） |

**WS 信令**（复用 `/ws/im` 白名单 +3）：

- `pet_invite`：领养邀请（对方聊天页弹卡）→ `pet_accept` 同意，服务端建 pair 记录回执双方。
- `pet_action`：互动/投喂动作广播，对方在线且开着该会话时实时播放动画。

未领养时聊天页宠物位显示领养入口；删除好友 pair 记录保留（重加恢复）。

## 4. 客户端交互

### 4.1 好友聊天页（主场景）

- 背景改**中性灰纯色 + 轻微渐变**（建议 `#8A8F98 → #6E747E`，色值待定可调——灰底融合透明素材的杂边）。
- 宠物在输入框上方一侧循环播 idle；头顶：等级徽标 + 火焰天数。
- **点击宠物**：随机播放已解锁动作，头顶气泡：`前往宠物中心` / `投喂（5🎵）`。
- 对方互动/投喂经 WS 实时推来本地同步播放（云逗宠）。

### 4.2 宠物精灵页（专门 tab 页）

- **入口**：聊天页气泡 + 底部导航新增"精灵"tab。**不放"我的"页**。
- 顶部：宠物大图（可左右切换已拥有角色）、等级+经验条、音符余额、火焰天数。
- 子页/tab：
  - **今日任务**：签到卡（常驻顶部）+ 任务列表（进度 x/N、领取按钮）。
  - **投喂**：大按钮或长按连投，播 eat 动画 + 飘经验数字。
  - **角色**：商店列表（价格/门槛/购买）+ 我的角色（切换展示）。
  - **图鉴**：已解锁动作网格，未解锁灰显标注"Lv.N 解锁"。

### 4.3 素材约定

- 透明通道 PNG 帧序列（推荐）或 animated WebP；命名 `pets/<species>/<action>/<NN>.png`。
- 锚点底部居中，1:1 画布、宠物占高约 80%；每动作 6~12 帧，客户端 12fps。
- 必备动作：idle / eat / happy / jump，其余随解锁补充；缺素材用占位图联调。
